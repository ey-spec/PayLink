### E1. Accounts and Wallet

#### US-01 Register as a customer with a basic level (FR-1) · Must
As a new customer, I want to register so that I can use PayLink with a wallet.
- **Given** valid registration details, **when** I register, **then** an account is created with level **Basic** and a wallet with 0.00 EGP available and 0.00 EGP held.
- **Given** a phone number that is already registered, **when** I register, **then** the request is rejected with a clear reason and no second account is created.
- **Given** an agent account, **when** it tries to register a customer on their behalf, **then** the request is rejected, because registration is self-service only (D-8).

#### US-02 Upgrade a customer to verified (FR-2) · Should
As an admin, I want to upgrade a customer to Verified so that their limits are raised.
- **Given** a Basic customer, **when** an admin upgrades them, **then** their level becomes **Verified** and the daily limit changes from 5,000 to 30,000 EGP (read from configuration).
- **Given** a customer who is already Verified, **when** an admin upgrades them again, **then** nothing changes and the system says so.

#### US-03 View available and held balance (FR-3) · Must
As a customer, I want to see my available and held balance so that I know what I can spend.
- **Given** a wallet with 1,000 EGP available and 352.50 EGP held, **when** I open my wallet, **then** I see both amounts.
- **Given** a hold is released or confirmed, **when** I view my wallet, **then** the amounts match the ledger exactly.

#### US-04 View transaction history (FR-3) · Must
As a customer, I want to see my transaction history so that I can check every movement.
- **Given** I have top-ups, holds, charges and releases, **when** I open my history, **then** I see each entry with type, amount, date and payment reference, newest first.
- **Given** I have no transactions, **when** I open my history, **then** I see an empty list and no error.

#### US-05 Top up the wallet by simulated card (FR-4) · Must
As a customer, I want to top up by card so that I have money to pay bills.
- **Given** a valid simulated card and an amount, **when** I top up, **then** my available balance increases by that amount and a ledger entry is created.
- **Given** a declined simulated card, **when** I top up, **then** the balance does not change, no ledger entry is created, and I see a clear reason.

#### US-06 Top up the wallet by agent cash (FR-4) · Must
As a customer, I want an agent to top up my wallet with my cash so that I can use PayLink without a card.
- **Given** an agent receives cash from me, **when** the agent confirms the top-up, **then** my available balance increases by that amount and a ledger entry records the agent as the source.
- **Given** an account that is not an agent, **when** it tries an agent-cash top-up, **then** the request is rejected.

#### US-07 Record a ledger entry for every balance change (FR-5) · Must
As the system owner, I want every balance change recorded as a ledger entry so that balances can always be proven.
- **Given** any top-up, hold, release or charge, **when** it happens, **then** a new ledger entry is added with amount, type, wallet, reference and time, and no earlier entry is edited or deleted.
- **Given** a wallet, **when** its balance is calculated, **then** available and held balances equal the sum of its ledger entries.
- **Given** the balance would become negative, **when** a debit is attempted, **then** it is rejected and no entry is written.
